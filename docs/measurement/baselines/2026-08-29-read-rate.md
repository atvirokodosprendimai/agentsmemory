## Why this is not a baseline

T1's Stop Condition asks what would make the criterion impossible to fail:

> if every recall in the corpus were followed by a fetch, or none were, the rate would be 0 or 1 and
> no mechanism could move it. Check the spread before recording the baseline; a degenerate
> distribution is a finding, not a baseline.

**The spread is degenerate.** 90 of 91 is 98.9%, one fetch away from saturation. A mechanism that
made every hit perfectly trustworthy could move this figure by at most 1.1 points, and any movement
would be indistinguishable from noise at n=1 fetch.

The cause is not agent behaviour and should not be read as evidence about it. `drawer_fetches`
landed as migration 00036 on **2026-08-29** — the same morning as this measurement. The single
recorded fetch is the canary from that task's own verification. **The instrument has not been
running long enough to have observed anything.** A near-100% figure here means "almost nothing has
been recorded yet", not "almost every read is acted on immediately".

There is a second reason the denominator is soft: `SkipTelemetry` means some recalls write no
`search_events` row at all, so 91 is recalls LOGGED and not recalls that happened. The rule already
says this; it matters more than usual when the numerator is 1.

## What has to happen before a mechanism ships

ADR-044 F-5 says no mechanism ships before a baseline is recorded. This file records that **the
baseline has been attempted and cannot yet be taken**, which is not the same thing and must not be
read as satisfying F-5.

Re-take it once `drawer_fetches` has accumulated fetches across more than one session — enough that
`recalls_fetched` is a distribution rather than a canary. At that point either:

- the spread is non-degenerate and this file is superseded by a real baseline, or
- the spread is still degenerate, which is itself the finding: if agents essentially never fetch
  after a recall, then "reads acted on without a second call" cannot discriminate, and the quantity
  has to be re-decided with the owner — a rule change, which under F-6 voids anything measured
  under this one.
